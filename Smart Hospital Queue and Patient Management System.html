      How the queue decides

      Critical patients are always called before urgent ones, and urgent before normal. Patients with the same priority are served in the order they arrived, so nobody waits forever behind a later arrival of equal urgency.

      Core of the C implementation

      The heap insert that keeps the most urgent patient at the top.

      typedef struct {
    int  token;      /* arrival order */
    char name[30];
    int  age;
    int  priority;   /* 1 critical, 2 urgent, 3 normal */
} Patient;

Patient heap[MAX];
int size = 0;

int higher(Patient a, Patient b) {
    if (a.priority != b.priority) return a.priority < b.priority;
    return a.token < b.token;
}

void insert(Patient p) {
    int i = size++;
    heap[i] = p;
    while (i > 0 && higher(heap[i], heap[(i - 1) / 2])) {
        Patient t = heap[i];
        heap[i] = heap[(i - 1) / 2];
        heap[(i - 1) / 2] = t;
        i = (i - 1) / 2;
    }
}
